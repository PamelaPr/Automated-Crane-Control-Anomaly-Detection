This project develops an AI/ML-based anomaly detection and root cause analysis system for a Hot Metal Crane Control System using industrial PLC telemetry data.
The system analyzes:
crane operational outputs
PLC control signals
acknowledgement signals
emergency stop events
switching activities
to predict whether the crane system is:
Healthy
Unhealthy / Faulty
The project uses:
time-series preprocessing
feature engineering
machine learning
operational intelligence
root cause analysis
to create an intelligent industrial monitoring solution.
